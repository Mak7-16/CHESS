## Шаховий Telegram-бот ♟️

Повноцінний шаховий бот з навчанням, міні-іграми та системою прогресу.

### Можливості

**🎮 Ігри**
- Шахові загадки (серії, звання)
- ⚡ Полювання — перемагай бота без зупинки, складність росте
- 🎯 Вгадай хід — вибір з 4 варіантів
- 🤖 Гра з ботом (3 рівні + підказка ходу)
- 🌐 Онлайн-матчі

**📚 Навчання**
- Уроки з прикладами на дошці
- 📖 8 класичних дебютів
- 🧠 Вікторина (15+ питань)
- 📅 Загадка дня (+40 XP раз на день)

**🏆 Прогрес**
- Система XP і 6 рівнів (від 🌱 Новачка до 👑 Гросмейстера)
- 10 досягнень
- Рейтинг топ-10 гравців

**💡 Інше**
- Випадкові факти та поради тренера

### Встановлення

```bash
npm install
cp .env.example .env
# Вставте TELEGRAM_TOKEN у .env
npm start
```

### Структура

```
bot.js
src/
  handlers.js   — команди
  features.js   — нові режими
  profile.js    — XP, рейтинг, досягнення
  game.js       — логіка гри та полювання
  puzzle.js     — загадки
  quiz.js       — вікторина
  guess.js      — вгадай хід
  openings.js   — дебюти
  facts.js      — факти
```
