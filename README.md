## Шаховий Telegram-бот ♟️

Повноцінний шаховий бот з навчанням, міні-іграми та системою прогресу.

### Можливості

**🎮 Ігри**
- Шахові загадки, бліц 2 хв, полювання, вгадай хід
- Гра з ботом (3 рівні), онлайн, 2 гравці на телефоні
- Виклик друга: `/challenge` та `/join КОД`

**📚 Навчання**
- Уроки, 8 дебютів, легендарні партії, ендшпіль, нотація
- Вікторина, загадка дня

**🏆 Прогрес**
- XP, 6 рівнів, 10 досягнень, рейтинг
- Щоденні квести, колесо удачі, серія входів
- Магазин титулів за XP

**✨ Ще**
- Обміни фігур, кращий хід, картки фігур
- Аналіз позиції, міні-турнір, гра на пам’ять
- Факти та поради тренера

### Встановлення

```bash
npm install
cp .env.example .env
# Вставте TELEGRAM_TOKEN у .env
npm start
```

### Структура

```
bot.js
src/
  handlers.js      — команди
  features.js      — основні режими
  moreFeatures.js  — квести, колесо, бліц, виклик
  extraFeatures.js — додаткові міні-ігри
  game.js, puzzle.js, profile.js, ...
```
