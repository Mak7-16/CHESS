## Шаховий Telegram-бот

Бот з уроками, грою проти ШІ та онлайн-матчами між гравцями.

### Можливості

- **Уроки** — 5 інтерактивних уроків з прикладами на дошці
- **Гра з ботом** — три рівні складності (легко / середньо / важко)
- **Гра онлайн** — пошук суперника серед інших користувачів бота

### Встановлення

```bash
npm install
```

### Налаштування

1. Скопіюйте `.env.example` у `.env`
2. Вставте токен від [@BotFather](https://t.me/BotFather):

```
TELEGRAM_TOKEN=ваш_токен
```

### Запуск

```bash
npm start
```

### Як грати

1. Натисніть `/start` або `/menu`
2. Оберіть режим у меню
3. Для ходу: натисніть свою фігуру, потім клітинку призначення

### Структура проєкту

```
bot.js           — точка входу
src/
  handlers.js    — обробники команд і кнопок
  game.js        — логіка гри
  engine.js      — ШІ суперника
  lessons.js     — контент уроків
  ui.js          — дошка та клавіатури
  store.js       — стан сесій і ігор
```
